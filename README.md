# Clear Sand - Robot Recolector de Residuos

## Descripción
Proyecto de innovación del Instituto Tecnológico Nacional Campus Tuxtlam. Clear Sand es un robot recolector y clasificador de residuos diseñado para limpiar playas, identificando y separando automáticamente residuos plásticos y metálicos.
